AIF-C01 標籤練習

Domain 1 · Task 1.1

這是 Louis Hui 的個人練習網頁，用來記憶 AWS Certified AI Practitioner（AIF-C01）Domain 1 Task 1.1 的官方英語術語。 介面是繁體中文；考試術語保持官方英語拼寫。你可以用「遮標籤」先隱藏術語，再逐個揭開，做提取練習（retrieval practice）。

使用方法

  1. 選一張練習圖，預設是「逐個揭開」：全部官方英語術語先遮住。
  2. 先嘗試回想術語，再點（或用鍵盤 Enter／空白鍵）揭開核對。
  3. 「顯示全部」會揭開所有標籤；「全部遮住」只遮住、點擊不會揭開，方便先看結構。
  4. 「重新遮住」會再次遮蓋所有術語。繁體中文提示會與對應英語術語一併遮蓋，避免直接洩漏答案。
